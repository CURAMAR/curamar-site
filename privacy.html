PRIVACY POLICY

プライバシーポリシー

最終更新: 2026年10月12日（v0.9.10 に合わせて全面的に書き直しました）
本ポリシーは、curamar が運営するウェブサイト curamar.space と、配信支援ツール Ligastmir（以下「本ソフト」）における、情報の取り扱いについて説明するものです。 本ソフトは「開発者は何も集めない・データは利用者（配信者）のパソコンの中だけに置く・外へ送るものはここに全部書く」という方針で作っています。

1. Ligastmir（本ソフト）について

1-1. 開発者が集めるもの

ありません。本ソフトが、利用者や視聴者の情報を開発者（curamar）や第三者のサーバーへ送ることはありません。 利用者の氏名・住所・連絡先を集めることも、行動を追跡することもありません。 開発者が中身を見るのは、利用者がご自身で報告用のファイルを送ってくれたときだけです（1-5）。

1-2. 利用者のパソコンの中に保存されるもの

以下は、すべて配信者のパソコンの中だけに保存されます（開発者を含む第三者は見られません）。 置き場所は、zip 版は Ligastmir.exe と同じフォルダです（インストーラー版〈v1.0.0 で配布予定・準備中〉は %LOCALAPPDATA%\Ligastmir）（アプリの「詳細設定 → 📂 データの置き場所」で開けます）。

  • ファン名簿（コメントした人の表示名・コメントの回数・最初と最後の日時・どの配信先か）。常連バッジ・「初見」の判定に使います。
  • コメントログ（記録を ON にしたときだけ・配信ごとのファイル・時刻・配信先・名前・コメント）。CSV に書き出すこともできます。
  • チャンネルポイントの集計（Twitch のユーザー ID ごとの回数と合計値だけ・名前や発言は持ちません）。
  • 設定・読み上げ辞書・着せ替え素材・動作ログ（ust_debug.log）。動作ログにはコメントの本文と視聴者の名前を書きません（文字数などだけ）。
  • 設定・辞書・名簿・集計の控え（バックアップ）。起動のたびに自動で作り、既定 10 世代まで。控えにも下の保存期間をかけます。
  • 連携サービスの API キーや認証トークン。お使いのパソコン固有の情報から作った鍵で暗号化して保存します（別のパソコンでは読めないので、移したときは入れ直しが必要です）。

1-3. 保存期間と、消し方

YouTube から受け取った視聴者の情報は 30 日で消えます（変えられません）
ファン名簿の YouTube の人は最後のコメントから 30 日で、コメントログの YouTube の行は 30 日で、自動的に消します（控えからも）。 YouTube API サービスの決まり（API で受け取ったデータを保存できるのは 30 日まで）に合わせています。 そのため、YouTube の人の常連バッジの回数は、30 日コメントが無いと最初からになります。
  • Twitch のコメントログ: 既定は 30 日で自動的に整理します（7 日／90 日／しない も選べます）。
  • ファン名簿の Twitch の人: 既定は消しません（常連バッジの回数の土台のため）。「最後のコメントから 90 日／180 日／1 年」で消す設定もあります。
  • 人ごとに消す: 名簿の ✕、または「名前を指定して消す」（名簿の表に出ていない人も）で、その人を名簿とコメントログ（控えも）から消せます。
  • 記録しない: 「記録しない人」に入れた名前は、名簿にもコメントログにも残しません（今ある記録も消します）。名前は、コメント欄に出る名前でも Twitch の ID（英数字）でもかまいません。
  • YouTube の分をいま消す: 名簿の YouTube の人・コメントログの YouTube の行を、30 日を待たずにまとめて消せます。

視聴者の方へ: これらのデータは、配信者のパソコンの中にあり、開発者は持っていません。 記録の削除や「記録しないでほしい」というご希望は、その配信の配信者にお伝えください（上の機能で対応できます）。

1-4. 外部のサービスへ送られるもの

本ソフトは、利用者が選んで有効にした機能に限り、以下の外部サービスと通信します。下の「常時おこなう通信」を除き、どの連携も利用者がオンにしたときだけ動きます。

常時おこなう通信（画面の書体の読み込み）
操作画面と、OBS に表示する各画面（字幕・コメントビュー・弾幕・アラート・ピックアップ・看板テロップ・視聴者数）は、 表示に使う書体を Google Fonts（fonts.googleapis.com / fonts.gstatic.com）から読み込みます。 画面を開いたときに毎回おこなわれ、オフにする設定はありません。送られるのは書体の取得に伴う一般的な情報（IP アドレス・ブラウザの種類など）で、 コメント・視聴者名・字幕の内容は送られません。Google のプライバシーポリシーが適用されます。 ※ ネットに繋がっていない環境では、パソコンの標準の書体で表示されます（機能は動きます）。
翻訳（重要）
翻訳を有効にすると、翻訳する文（コメント・字幕）が、外部の翻訳サービスに送られます。 使う順番は DeepL（キーを入れたとき）→ Google 翻訳 → MyMemory → LibreTranslate（有志が運営する公開サーバー: lt.vern.cc / translate.fedilab.app）で、うまくいかないときは次に回ります。 Google 翻訳は、Google の公式の API ではなく、人が使う Web の翻訳画面を使っています（Google の利用規約の「自動でのアクセス」の決まりに触れうる使い方です。Google に止められたときは自動で次に回ります）。 MyMemory に連絡用のメールアドレスを入れた場合は、そのアドレスも MyMemory へのリクエストに付きます（枠を広げるため）。 各サービスのプライバシーポリシー・利用規約が適用されます。翻訳をオフにすれば、これらへの送信は行われません。
音声認識（字幕）
字幕の音声認識を使うと、マイクの音声が Microsoft の音声認識サービスへ送られます（Microsoft Edge の仕組み〈WebView2 と見えない Edge〉で文字にしているため）。 Microsoft のプライバシーに関する声明が適用されます。字幕を止めている間は送られません。
  • Twitch: コメントの受信（チャンネル名だけで匿名で接続）・通知（フォロー・サブスク・チャネポなど）・配信情報（タイトル・カテゴリ・タグ）・視聴者数の取得のため、Twitch と通信します（利用者が接続・認証したとき）。 次の機能をオンにしたときは、配信者のアカウントで Twitch のチャットに投稿します: 翻訳の代理投稿（Twitch のコメントの訳だけ）・定期コメント・リアクションの返信・自動シャウトアウト・チャネポの返信。
  • YouTube: ライブチャットの受信・視聴者数の取得（API キー。API キーでは読めない非公開・メンバー限定の配信のチャットだけは、Google 認証の権限で読みます）と、配信情報（タイトル・説明・サムネイル）の変更（Google 認証）のため、YouTube Data API と通信します（利用者が接続・認証したとき）。
  • VOICEVOX / 棒読みちゃん: 読み上げのため、お使いのパソコン上のこれらのソフトに読み上げる文を渡します（パソコンの中だけの通信）。
  • わんコメ（OneComme）: 同伴起動を使う場合、お使いのパソコンにインストール済みのわんコメ本体を起動・終了します（データのやり取りはしません）。
  • OBS: シーンの切り替えなどのため、お使いのパソコン上の OBS と通信します（パソコンの中だけの通信）。
  • 更新のお知らせ: 「更新を確認する」をオンにしたときだけ、最新版の情報（version.json）を curamar.space から取得します（既定はオフ）。

1-5. 不具合の報告でファイルを送るとき

ツールには、動作ログを zip にまとめる機能があります。送るかどうかは、すべて利用者ご自身の操作によります（ツールが自動で送ることはありません）。 この zip には設定・認証情報・コメントログを入れません。動作ログにもコメントの本文と視聴者の名前は書いていません。 それでも、送る前に中身をご確認ください。

1-6. YouTube API サービスの利用について

本ソフトは YouTube API Services を利用しています。本ソフトの YouTube 連携機能を利用する場合、利用者は YouTube の利用規約 に同意したものとみなされ、また Google プライバシーポリシー が適用されます。本ソフトは、YouTube から受け取った情報を、上記の連携機能を提供する目的以外には使いません（保存期間は 1-3）。

本ソフトに与えた Google アカウントへのアクセス権限は、 Google アカウントの「サードパーティのアクセス」 からいつでも取り消せます。本ソフトの「ログアウト（取り消し）」を押した場合も、手元の認証情報を消し、Google 側の許可も取り消します。

2. ウェブサイト（curamar.space）について

2-1. アクセス解析

本サイトでは、訪問者数やどのページが見られているかを把握するために、アクセス解析を利用しています。 これは本サイトの改善のために、閲覧の傾向を統計的に把握する目的で用いるものです。 個人を特定する目的では利用しません。

2-2. 外部リンク

本サイトには Twitch、カクヨム、Discord などの外部サービスへのリンクが含まれます。 リンク先での情報の取り扱いについては、各サービスのプライバシーポリシーをご確認ください。

3. お問い合わせ

本ポリシーや情報の取り扱いについてのご質問は、Discord またはサイト上の連絡先からお寄せください。

4. 改定について

本ポリシーの内容は、機能の追加やサービスの変更に応じて改定することがあります。 重要な変更がある場合は、本ページ上で告知します。
